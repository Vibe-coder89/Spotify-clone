# Spotify Clone

A simple **Spotify Clone** built using basic web technologies. This project is made for learning and practice purposes and focuses on recreating the look and feel of Spotify.

---

## Features

* Spotify-like user interface
* Play and pause songs
* Music progress bar
* Playlist layout
* Responsive design

---

## Technologies Used

* HTML
* CSS
* JavaScript

---

## Live Repository

🔗 GitHub Repo: [https://github.com/Vibe-coder89/Spotify-clone](https://github.com/Vibe-coder89/Spotify-clone)

---

## How to Run

1. Clone the repository

   ```bash
   git clone https://github.com/Vibe-coder89/Spotify-clone.git
   ```
2. Open the project folder
3. Open `index.html` in your browser
